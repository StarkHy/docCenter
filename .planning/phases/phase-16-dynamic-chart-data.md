# Phase 16: 图表数据动态绑定

**优先级**: P0 (最高)  
**预计工作量**: 3 天  
**状态**: 📋 待规划

---

## 目标

实现图表配置与数据源分离：
- 图表样式（类型、标题、单位、颜色等）在映射中手动配置
- 图表数据从数据源动态获取，不再是静态配置

---

## 背景

当前图表配置方式（静态）：
```json
{
  "id": "revenue_trend",
  "type": "line",
  "title": "收入趋势",
  "x_data": ["1月", "2月", "3月"],
  "y_data": [100, 120, 150]
}
```

问题：
- 数据硬编码在映射配置中，无法从数据源动态获取
- 数据变化时需要手动修改映射配置
- 无法实现数据的动态筛选和更新

目标配置方式（动态）：
```json
{
  "id": "revenue_trend",
  "type": "line",
  "title": "收入趋势",
  "x_field": "month",
  "y_field": "revenue",
  "unit": "万元"
}
```

---

## 技术方案

### 数据流
1. 用户在映射中配置图表：选择数据源 → 选择 x 字段 → 选择 y 字段
2. 生成文档时，先从数据源获取完整数据
3. 提取指定字段的数据生成图表
4. 将图表嵌入 Word 文档

### 兼容性
- 保留现有的静态数据配置方式
- 新增字段映射配置时优先使用动态数据
- 静态数据作为后备
