Refactor TemplateService to use TemplateRepository instead of direct session.execute() calls.

Changes needed:
1. Add TemplateRepository as constructor parameter to TemplateService
2. Replace all `await session.execute(select(...))` calls with repository methods
3. Use repository methods: get_by_id, get_all, add, update, delete, get_paginated, get_by_name
4. Maintain backward compatible interface - services can still be called with session parameter but use repository internally
5. Keep storage_service usage for file operations (not a DB concern)

Key replacements:
- `session.execute(select(Template).where(...))` → `template_repo.get_by_id(id)` or `template_repo.get_all()`
- `session.execute(select(func.count(...)))` → `template_repo.get_paginated()`
- `session.execute(select(Template).offset(...).limit(...))` → `template_repo.get_paginated()`
- Direct Template() creation → `template_repo.add(template)` 
- `session.delete(template)` → `template_repo.delete(id)`
